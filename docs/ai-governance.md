# AI Governance

The system is human-in-the-loop.

AI can:
- detect anomalous telemetry
- estimate failure probability
- estimate RUL
- prioritize assets
- produce reason codes

AI cannot:
- command a PLC
- alter a setpoint
- shut down equipment
- bypass a safety system
- autonomously create production maintenance orders

Every prediction carries model version, confidence, data-quality and drift indicators.
